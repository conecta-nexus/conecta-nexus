# conecta-nexus

Repo de entrada para sincronizar todos los microservicios, frontend, gateway e infraestructura.

### Ejecutar

el script [`setup.sh`](./setup.sh), si no está clonado uno de los respositorios, lo clonará en el entorno local. Si ya existe, intentará hacer fetch / pull para sincronizar main y develop, y si hay errores los notificará en la terminal.
